# Lådans hemlighet

En lekfull matteapp som visar hur man ställer upp och löser en ekvation om ett rätblock (en låda), steg för steg.

Starttal: Volymen är 36 dm³, höjden är 2 dm och bredden är hälften av längden.
`36 = l · l/2 · 2` → `36 = l²` → `l = 6`, `b = 3`.

- Ekvationen visas som en våg som tippar när man provar sig fram.
- Lådan byggs kub för kub för att kontrollera svaret.
- Knappen "Nytt tal" skapar nya uppgifter på tre nivåer (Lätt, Mellan, Svår).

Öppna `index.html` i en webbläsare, eller besök GitHub Pages-sidan.
